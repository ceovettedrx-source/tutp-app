# Play Console: content rating questionnaire (IARC) answers

Category to choose: **Reference, News, or Educational** (not Social or Game). Answers below are what the app does today; the account owner submits them and must answer for the build in the test.

| Question | Answer | Why |
|---|---|---|
| Violence / blood / graphic content | No | stories and quizzes are school-topic content; the story prompt keeps it child-suitable |
| Sexual content or nudity | No | |
| Profanity or crude humour | No | |
| Controlled substances (drugs, alcohol, tobacco) | No | |
| Gambling or simulated gambling | No | Play-Based Learning is a quiz with scores, no stakes |
| Fear / horror | No | |
| Users can interact or exchange content with each other | No | no chat, no public profiles; Play-Based Learning is a quiz played by people in the same family on joining codes, no messages |
| Shares the user's location with others | No | |
| Allows purchases of digital goods | Yes | Pro / Annual Pro plans (see the Play Billing decision in the founder list) |
| Unrestricted internet access / web browser | No | the app opens only tutp.online; external links open in the browser |
| Generative AI features | Yes | answers, stories, notes and quizzes are written by AI from what the user types or photographs |
| Does the app have news / unmoderated user-generated content that others can see? | No | content is private to the family |

Expected result: **IARC 3+ / PEGI 3 / Everyone**. Re-answer if a chat, leaderboard between strangers or any public sharing is ever added.

## Policy points that come with the AI answer
- Google's AI-Generated Content policy wants an **in-app way for users to report offensive AI output**. The app has answer feedback buttons (`feedback.submitted`) and "Is this picture wrong?" on story pictures. Founder to confirm the feedback button is reachable on every AI result screen and that reports reach someone (they are classified and escalated by email today).
